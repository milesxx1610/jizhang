# 记账

每一笔，都有迹可循。

一款面向 iPhone 的记账应用，用于记录日常收支、查看账目和了解预算情况。

## 功能

- 记录、编辑和删除收入与支出，填写分类、日期和备注。
- 按月份查看账目，搜索分类或备注。
- 查看收支统计并设置月度预算。
- 导出和导入账目备份。

## 使用要求

- iPhone，iOS 17.0 或更高版本。
- 当前版本：1.1。

## 数据与备份

账目保存在设备本地。删除 App 可能同时删除本地数据，请先在应用中导出备份，并妥善保存备份文件。

## 构建与安装

项目使用 SwiftUI 和 XcodeGen。仓库内提供手动运行的 GitHub Actions 工作流，可以生成未签名 IPA。未签名 IPA 需要另行签名后才能安装；当前尚未提供 App Store 安装方式。
